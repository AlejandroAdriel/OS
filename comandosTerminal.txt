================================================================================
GUÍA DE COMPILACIÓN Y PRUEBA POR TÉCNICAS OS
================================================================================
Este manual contiene los comandos detallados y paso a paso para compilar y probar
cada programa de forma legible e individualizada.

Banderas de compilación recomendadas:
  GCC: -Wall (advertencias), -lpthread (hilos/POSIX), -lrt (tiempo real e IPC)
  G++: -std=c++17 -Wall -lpthread

================================================================================

13. GUÍA DE COMPILACIÓN Y PRUEBA DE LAS 55 DUPLAS (combinaciones/duplas)
================================================================================

Las duplas combinan exactamente 2 técnicas independientes.
Cada carpeta en combinaciones/duplas/ contiene su programa principal:
  - 'program.c' (para implementaciones en C)
  - 'program.cpp' (para implementaciones en C++)
  - 'hijo.c' (programa secundario adicional en las duplas que usan Execv)

A continuación se muestran ejemplos detallados paso a paso para cada categoría de dupla:

[Duplas en C (Ejemplo: Pipe + Fork)]
  Carpeta: combinaciones/duplas/pipeFork/
  Pasos:
    cd combinaciones/duplas/pipeFork
    gcc program.c -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas en C (Ejemplo: Shared Memory + Semáforos)]
  Carpeta: combinaciones/duplas/sharedMemorySemafora/
  Pasos:
    cd combinaciones/duplas/sharedMemorySemafora
    gcc program.c -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas en C (Ejemplo: Signalización + FIFO)]
  Carpeta: combinaciones/duplas/signalizacionFifo/
  Pasos:
    cd combinaciones/duplas/signalizacionFifo
    gcc program.c -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas en C++ (Ejemplo: Locks + Variable Condicional)]
  Carpeta: combinaciones/duplas/locksCondicionalVariable/
  Pasos:
    cd combinaciones/duplas/locksCondicionalVariable
    g++ -std=c++17 program.cpp -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas en C++ (Ejemplo: Message Passing + Locks)]
  Carpeta: combinaciones/duplas/messagePassingLocks/
  Pasos:
    cd combinaciones/duplas/messagePassingLocks
    g++ -std=c++17 program.cpp -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas con Execv (Ejemplo: Execv + Fork)]
  Carpeta: combinaciones/duplas/execvFork/
  Pasos:
    cd combinaciones/duplas/execvFork
    gcc hijo.c -o hijo
    gcc program.c -o run -lpthread -lrt
    ./run
    cd ../../..

[Duplas con Execv (Ejemplo: Dup2 + Execv)]
  Carpeta: combinaciones/duplas/dup2Execv/
  Pasos:
    cd combinaciones/duplas/dup2Execv
    gcc hijo.c -o hijo
