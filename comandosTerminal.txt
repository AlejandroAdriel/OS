Este archivo contiene los comandos exactos y funcionales para compilar y probar
todos los programas del proyecto organizados en carpetas (excluyendo kernel).

--------------------------------------------------------------------------------
1. COMANDOS ÚTILES DEL SISTEMA E IPC
--------------------------------------------------------------------------------
- Ver procesos:            ps -ef | grep <nombre>   |   pstree -p
- Ver hilos activos:       ps -eLf | grep <nombre>
- Listar IPCs activos:     ipcs -a  (o -m para memoria, -q para colas, -s para semáforos)
- Limpiar todos los IPC:   ipcrm -a (o: ipcs -m | awk '{print $2}' | xargs -n1 ipcrm -m 2>/dev/null)
- Enviar señales:          kill -SIGUSR1 <PID>  |  kill -SIGINT <PID>  |  kill -9 <PID>

5. COMPILACIÓN Y PRUEBA DE LAS 55 DUPLAS (combinaciones/duplas)
--------------------------------------------------------------------------------

[Patrón General para cualquier dupla en C]
  cd combinaciones/duplas/<nombreDupla>
  gcc program.c -o run -lpthread -lrt
  ./run
  cd ../../..

[Patrón General para cualquier dupla en C++]
  cd combinaciones/duplas/<nombreDupla>
  g++ -std=c++17 program.cpp -o run -lpthread -lrt
  ./run
  cd ../../..

[Patrón para duplas que usan Execv]
  cd combinaciones/duplas/<duplaConExecv>
  gcc hijo.c -o hijo
  gcc program.c -o run -lpthread -lrt   # (o g++ -std=c++17 si es .cpp)
  ./run
  cd ../../..

6. SCRIPT ONE-LINER PARA COMPILAR Y COMPROBAR TODO EL REPOSITORIO
--------------------------------------------------------------------------------

Para verificar en 3 segundos que todos los programas C y C++ compilan sin fallos:

  python3 -c '
import glob, subprocess
c = [f for f in glob.glob("**/*.c", recursive=True) if not f.startswith("kernel")]
cpp = [f for f in glob.glob("**/*.cpp", recursive=True) if not f.startswith("kernel")]
errs = []
for f in c:
    if subprocess.run(["gcc", "-c", f, "-o", "/dev/null", "-lpthread", "-lrt"], capture_output=True).returncode != 0: errs.append(f)
for f in cpp:
    if subprocess.run(["g++", "-std=c++17", "-c", f, "-o", "/dev/null", "-lpthread"], capture_output=True).returncode != 0: errs.append(f)
print(f"Todo correcto: {len(c)+len(cpp)} programas compilados exitosamente." if not errs else f"Errores en: {errs}")
'
